# Contributing to Trama

Thank you for helping. Trama is used for research with real people's words, so correctness, privacy and plain language matter more than speed.

## Before you start

- For anything beyond a small fix, open an issue first so we can agree on the approach.
- **Never use real research data** in issues, pull requests, tests, fixtures or screenshots — no real transcripts, recordings, field notes or participant details, not even pseudonymised or with names changed. Use invented material, like the example project in `app/src/demo/`.
- Be kind; see the [Code of Conduct](CODE_OF_CONDUCT.md).

## Development

See [AGENTS.md](AGENTS.md) for the commands and the architecture, and [docs/platforms.md](docs/platforms.md) for building on each system. The checks every pull request must pass:

```bash
npm run typecheck     # also fails on any missing translation
npm test
npm run lint:rust
npm run test:rust
npm run check:privacy --workspace @trama/app
```

Test user-interface changes in the browser demo (`npm run dev:web`), in light and dark themes, at a small window (1000 × 660) and at a fractional scale (125 %), and check that everything can be done from the keyboard.

## Three languages

Trama ships in English, European Portuguese and European Spanish, and everything user-facing must exist in all three: the interface, the manual and the privacy text.

- A change that adds or changes visible text updates the three catalogs in `app/src/core/i18n/locales/{en,pt,es}/` in the same commit; the typecheck fails otherwise.
- A change in how something is done updates the manual in `docs/manual/{en,pt,es}/`. Sections keep the same `<a id>` anchors in every language; `app/src/features/help/manual.test.ts` checks it.
- Portuguese is from Portugal (ecrã, ficheiro, frase-passe, guardar) and Spanish from Spain (ordenador, archivo, contraseña, guardar), addressing the reader formally. Keep to the glossary in AGENTS.md.
- If you do not write one of the languages, say so in the pull request and we will help. Please do not submit machine translation unreviewed.

## Privacy

Trama makes no network connections. Pull requests that add network access, analytics, telemetry or remote content will not be accepted. Anything that writes research data outside the encrypted library (a new export, a new file type, a new clipboard action) must be added to `app/src/core/privacy/flows.ts`, with `PRIVACY.md` regenerated by `npm run gen:privacy`.

## Sign-off (DCO)

We use the [Developer Certificate of Origin](https://developercertificate.org/). Sign off every commit to certify that you wrote it or have the right to submit it under the project's licence:

```bash
git commit -s -m "Explain what changed and why"
```
