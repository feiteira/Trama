# Glossário

**Alfa (α) de Krippendorff** — Uma estatística de concordância semelhante ao kappa, em que o acaso é estimado a partir das etiquetas dos dois codificadores juntas.

**Área de transferência** — O sítio onde o computador guarda o que copia, até copiar outra coisa. Outros programas podem lê-lo.

**Atributo** — Uma variável que descreve todos os casos: idade, função, bairro. Cada um tem um tipo (texto, número, data, sim/não ou escolha). Ver [Atributos](06-cases-and-attributes.md#attributes).

**Biblioteca** — Todos os seus projetos num computador, desbloqueados por uma frase-passe. Ver [Primeiros passos](01-getting-started.md).

**Caso** — Uma unidade de análise, normalmente um participante; também um local, um agregado familiar ou uma organização. Um documento pertence, no máximo, a um caso. Ver [Casos](06-cases-and-attributes.md#cases).

**Categoria** — Um código que apenas agrupa outros códigos e não se pode aplicar ao texto.

**Chave de pseudonimização** — A lista do que substituiu o quê. São dados pessoais: fica no projeto cifrado e fica de fora das exportações, a menos que a inclua.

**Codificação** — O ato de aplicar códigos a passagens; também se usa para um segmento codificado.

**Codificador** — Quem codifica num projeto. Cada segmento codificado, memorando e entrada do registo de auditoria é assinado pelo seu codificador. Ver [Codificadores](08-teamwork-and-agreement.md#coders).

**Código** — Uma etiqueta curta para uma ideia, aplicada a passagens de texto. Os códigos formam uma hierarquia no livro de códigos.

**Código ativo** — Um código escolhido no painel de códigos quando não há texto selecionado. A definição aparece no fundo do painel, e pode mostrar só as suas codificações no documento. Ver [O painel de códigos](03-coding.md#codes-panel).

**Código favorito** — Um código com uma tecla de atalho de 1 a 9, que se aplica ao texto selecionado premindo essa tecla.

**Código in vivo** — Um código com o nome tirado das próprias palavras do participante. Ver [Códigos in vivo](03-coding.md#in-vivo).

**Concordância entre codificadores** — Até que ponto dois codificadores codificaram o mesmo material de forma semelhante. Ver [Comparar dois codificadores](08-teamwork-and-agreement.md#compare).

**Coocorrência** — Dois códigos aplicados a passagens sobrepostas, próximas ou no mesmo parágrafo. Ver [Coocorrência](07-analysis.md#cooccurrence).

**Coocorrência no texto** — Um filtro de segmentos codificados que se sobrepõem a, estão dentro de ou contêm segmentos de outros códigos. Ver [Filtros](05-retrieval-and-memos.md#filters).

**Cópia de segurança** — Um ficheiro `.trama` cifrado de um projeto inteiro, escrito automaticamente numa pasta à sua escolha. Ver [Cópias de segurança](10-privacy-and-security.md#backups).

**Documento** — Uma peça do material: uma transcrição, notas de campo, um relatório, um conjunto de respostas a um inquérito.

**Ficheiro `.trama`** — O ficheiro próprio do Trama para um projeto inteiro, um arquivo ZIP em formatos abertos, opcionalmente cifrado com palavra-passe. Ver [O ficheiro .trama](09-exchange.md#trama-file).

**Frase de recuperação** — Doze palavras que abrem a biblioteca se se esquecer da frase-passe. Guarde-as em papel. Ver [Anotar a frase de recuperação](01-getting-started.md#recovery-phrase).

**Frase-passe** — As palavras que escreve para desbloquear a biblioteca. Pelo menos 10 caracteres; algumas palavras sem relação entre si funcionam melhor.

**Fundir** — Juntar dois códigos num só. Ver [Fundir e separar códigos](04-codebook.md#merge-split).

**Grupo de documentos** — Um conjunto de documentos que pertencem juntos, como uma vaga ou um local. Um documento pode estar em vários grupos. Ver [Grupos de documentos](02-documents.md#groups).

**Índice de Jaccard** — Uma medida de coocorrência de 0 a 1 que tem em conta a frequência com que cada código é usado.

**Integrar** — Trazer a cópia de um projeto de um colega para a sua. Ver [Integrar a cópia de um colega](08-teamwork-and-agreement.md#merge).

**Kappa (κ) de Cohen** — Uma estatística de concordância que corrige a percentagem de concordância pela concordância esperada por acaso. Ver [Como se calculam as estatísticas](08-teamwork-and-agreement.md#statistics).

**Livro de códigos** — Todos os códigos de um projeto, organizados em árvore, com as cores e as definições. Ver [O livro de códigos](04-codebook.md).

**Marca de tempo** — Um ponto de uma transcrição ligado a um momento da gravação, usado para reproduzir a gravação a partir de uma passagem.

**Memorando** — A sua escrita analítica, sobre o projeto, um documento, um código, um segmento codificado ou um caso. Ver [Memorandos](05-retrieval-and-memos.md#memos).

**Palavra-chave em contexto (KWIC)** — Uma lista de ocorrências de uma pesquisa, cada uma com as palavras à volta, alinhadas pela ocorrência. Ver [Pesquisa de texto](07-analysis.md#search).

**Palavras vazias** — Palavras muito comuns (*o*, *e*, *de*) que ficam de fora da frequência de palavras.

**Paleta de comandos** — A caixa de pesquisa que se abre com `Ctrl+K` e encontra qualquer ecrã, documento, projeto ou ação.

**Projeto** — O material e a análise de um estudo: documentos, livro de códigos, segmentos codificados, memorandos, casos.

**Pseudonimização** — Substituir nomes e dados identificativos de forma coerente em todos os documentos. Ver [Pseudonimização](10-privacy-and-security.md#pseudonymisation).

**REFI-QDA** — O padrão aberto para trocar projetos (`.qdpx`) e livros de códigos (`.qdc`) entre programas de análise qualitativa. Ver [Trocar projetos](09-exchange.md).

**Registo de auditoria** — O registo, só de acrescento, de todas as alterações a um projeto: quem fez o quê, e quando. Ver [O registo de auditoria](10-privacy-and-security.md#audit-trail).

**Segmento codificado** — Uma passagem codificada com um código por um codificador. Vários códigos na mesma passagem são vários segmentos codificados.

**Transcrição** — Um documento com fala, uma intervenção por parágrafo, opcionalmente com gravação e marcas de tempo. Ver [Transcrições e gravações](02-documents.md#transcripts).
